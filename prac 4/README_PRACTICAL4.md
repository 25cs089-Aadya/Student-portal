# StudentHub — Practical 4

JavaScript DOM Manipulation, Event Handling, and UI Interactivity.

## Run
Open this folder in VS Code and right-click `home.html` → **Open with Live Server**.

## Demo checklist
- `aboutus.html`: FAQ expand/collapse
- `dashboard.html`: dismiss notification, next/previous content slider, open/close modal (button, backdrop, Escape)
- Any page: dark/light toggle, with persistent `localStorage` key `studenthub-theme`
- Resize to phone width (<700px): hamburger menu expands/collapses
- Keyboard accessibility: Tab focus, Enter/Space buttons, Escape modal/menu

## Files added
- `practical4.css`: new interactions, dark palette, responsive styles and animation.
- `practical4.js`: all DOM and event handling.
- `home.html`: homepage based on existing `homegrid.html`.

Original Practical 3 Flexbox and Grid files and styles are retained.
Links to `about.html` and `contact.html` were adjusted to the provided filenames `aboutus.html` and `contactus.html`.
